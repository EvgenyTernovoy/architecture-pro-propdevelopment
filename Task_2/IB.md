# Проверочный лист

В проверочный лист включены следующие разделы:

- Управление доступом - т.к сейчас есть проблемы с контролем данных и пользователи могут видеть данные других пользователей системы
- Безопасность данных - мы храним персональные и финансовые данные, но у компании есть проблемы с политиками безопасности API партнеров плюс нарушен контроль данных.
- Защита инфраструктуры - т.к у компании есть приватное облако и собственный цод, нам нужно провести аудит безопасности инфраструктуры и выработать методы защиты от угроз.
- Управление инцидентами - здесь мы должны убедиться, что компания способна своевременно реагировать на инциденты безопасности.
- Управление оборудованием и физической безопасностью - т.к у компании есть собственный ЦОД, нам необходимо убедиться в его безопасности и выработать подходы для управления оборудованием.
- Облачная инфраструктура - т.к компания пользуется приватным облаком мы должны уделить внимание правильности конфигурации ресурсов
